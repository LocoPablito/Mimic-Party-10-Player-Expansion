[size=5][b]10 Player Expansion for Mimic Party[/b][/size]
[b]Runtime 1.1.3 · by arribbaa[/b]

Up to [b]10 total players[/b] in private Classic and Versus lobbies. Versus keeps the game's RED/BLUE team selection; the mod does not force equal teams or a five-player quota per side.

[size=4][b]Required downloads[/b][/size]
[url=https://www.nexusmods.com/mimicparty/mods/3]BepInEx Pack for Mimic Party 1.0.1[/url]
[url=https://www.nexusmods.com/mimicparty/mods/2]Mimic Party Modding Core 1.0.0[/url]

[b]The main ZIP contains the Expansion only.[/b]

[size=4][b]Installation / update[/b][/size]
1. Close Mimic Party.
2. Install/update BepInEx Pack 1.0.1 into the folder containing Mimic Party.exe.
3. Install Core 1.0.0 into the same folder.
4. Extract this Expansion ZIP there; it adds/replaces BepInEx/plugins/MimicParty10PlayerExpansion.dll.
5. Launch through Steam and allow interop generation to finish when required.

[size=4][b]v0.2.3 update[/b][/size]
Runtime 1.1.3 adds explicit support for the captured Mimic Party v0.2.3 GameAssembly fingerprint. The game moved the shared Classic/Versus capacity helper but retained its exact unique signature and stock 5/4 behavior. The mod continues to patch that helper in memory and runs its live capacity self-check before reporting success.

The required max-player, playback voice and rematch hook targets remain present in the v0.2.3 interop assemblies. The new public room browser is not spoofed by patching RoomListing values; it is expected to reflect the actual session capacity and is part of live acceptance testing.

[size=4][b]Configuration[/b][/size]
[code][Multiplayer]
MaxPlayers = 10[/code]
Range: 6-10. Restart after changing it.

[size=4][b]Compatibility[/b][/size]
Supported captured fingerprints include v0.1.73 and v0.2.3. Unknown future game builds are not automatically supported.
[url=https://github.com/LocoPablito/Mimic-Party-10-Player-Expansion/blob/main/COMPATIBILITY.md]Exact hashes and verification details[/url]

[size=4][b]Removal and support[/b][/size]
Close the game and remove only BepInEx/plugins/MimicParty10PlayerExpansion.dll. Keep Core/Pack if other mods use them. Capacity patches are in memory and disappear at process exit.

For errors, include versions and a sanitized BepInEx/LogOutput.log excerpt.
