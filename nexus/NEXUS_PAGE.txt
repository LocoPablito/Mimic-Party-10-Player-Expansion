[size=5][b]10 Player Expansion for Mimic Party[/b][/size]
[b]Runtime 1.1.4 · by arribbaa[/b]

Up to [b]10 total players[/b] in private Classic and Versus lobbies. Versus keeps the game's RED/BLUE team selection; the mod does not force equal teams or a five-player quota per side.

[size=4][b]Required downloads[/b][/size]
[url=https://www.nexusmods.com/mimicparty/mods/3]BepInEx Pack for Mimic Party 1.0.2[/url]
[url=https://www.nexusmods.com/mimicparty/mods/2]Mimic Party Modding Core 1.0.0[/url]

[b]The main ZIP contains the Expansion only.[/b]

[size=4][b]Installation / update[/b][/size]
1. Close Mimic Party.
2. Install/update BepInEx Pack 1.0.2 into the folder containing Mimic Party.exe.
3. Install Core 1.0.0 into the same folder.
4. Extract this Expansion ZIP there; it adds/replaces BepInEx/plugins/MimicParty10PlayerExpansion.dll.
5. Launch through Steam and allow interop generation to finish when required.

[size=4][b]Removal and support[/b][/size]
Close the game and remove only BepInEx/plugins/MimicParty10PlayerExpansion.dll. Keep Core/Pack if other mods use them. Capacity patches are in memory and disappear at process exit.

For errors, include versions and a sanitized BepInEx/LogOutput.log excerpt.
